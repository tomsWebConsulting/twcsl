# Gallery Block Slideshow Auto Play

### [License][1]

### Synopsis

Auto play gallery blocks with design slideshow.

### Version

  * 0.1.0

#### Squarespace Versions

  * 7.1
  
  * 7.0

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].
  
  * [jQuery][4]

---

## Install

* Add the following to Website > Pages > Custom Code > Code Injection >
  HEADER.
  
  ```html
  <script src="https://ajax.googleapis.com/ajax/libs/jquery/3.7.1/jquery.min.js"></script>
  ```

* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Page.
    
    * Add code from file **[gallery block slideshow auto play.html][5]** to Page
      Settings > Advanced > Page Header Code Injection for the Page. Refer to
      [Inject code to a specific page][6] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Pages.
    
    * Add code from file **[gallery block slideshow auto play.html][4]** to
      Website > Pages > Custom Code > Code Injection > FOOTER. Refer to [Add
      code to the header and footer][7] for details.
      
* Read the code for any instructions within.

## Notes

This effect is not active in Squarespace Preview to test it use [private
browsing][8].

You can find block ids by using Heather Tovey's [Squarespace ID Finder][9].
