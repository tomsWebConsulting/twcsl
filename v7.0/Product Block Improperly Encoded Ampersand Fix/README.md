## Quick Install

* Add the following to Website > Pages > Custom Code > Code Injection >
  HEADER.
  
  ```html
  <script src="https://ajax.googleapis.com/ajax/libs/jquery/3.7.1/jquery.min.js"></script>
  ```
  
* Add code from file **[product block improperly encoded ampersand
  fix.html][2]** to Page Settings > Advanced > Page Header Code Injection for
  the Page.
