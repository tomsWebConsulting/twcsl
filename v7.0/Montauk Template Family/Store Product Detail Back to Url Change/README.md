## Install

* Install [twcsl][3].
  
* Add code from file **[store product detail back to url change.html][4]** to
  Store Settings > Advanced > Page Header Code Injection for the Store Page.
  Please see [Inject code to a specific page][5].
  
* Read the code for any instructions within.
