#### Squarespace Versions

  * 7.1

  * 7.0 ([Brine template family][2])

---

## Quick Install

* Add the following to Website > Pages > Custom Code > Code Injection >
  HEADER.
  
  ```html
  <script src="https://ajax.googleapis.com/ajax/libs/jquery/3.7.1/jquery.min.js"></script>
  ```
  
* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Page.
    
    * Add code from file **[image block image caption second add.html][3]** to
      Page Settings > Advanced > Page Header Code Injection for the Page. Refer
      to [Inject code to a specific page][4] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Pages.
    
    * Add code from file **[image block image caption second add.html][3]** to
      Website > Pages > Custom Code > Code Injection > FOOTER. Refer to [Add
      code to the header and footer][5] for details.

## Note

On v7.0 using the Brine template family an image block with design inline does
not show the second caption. This is a CSS issue and not an issue with the code.
In other words if you want it to show you need to overcome Squarespace's CSS
that hides the second caption by default.
