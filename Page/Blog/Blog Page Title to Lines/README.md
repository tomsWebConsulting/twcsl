# Blog Page Title to Lines

### [License][1]

### Synopsis

Split title into lines.

### Version

  * 0.1.0

#### Squarespace Versions

  * 7.1
  
  * 7.0

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Quick Install

* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Blog Page.
    
    * Add code from file **[blog page title to lines.html][4]** to
      Blog Settings > Advanced > Page Header Code Injection for the Blog Page.
      Refer to [Inject code to a specific page][5] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Blog Pages.
    
    * Add code from file **[blog page title to lines.html][4]** to Website >
      Pages > Custom Code > Code Injection > FOOTER. Refer to [Add code to the
      header and footer][6] for details.
      
* Read the code for any instructions within.
