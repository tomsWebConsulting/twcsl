# Store Page Detail Slideshow Item Badge Add

### [License][1]

### Synopsis

Add badges to product detail slideshow badges.

### Version

  * 0.3.0

#### Squarespace Versions

  * 7.1
  
  * 7.0 ([Brine template family][2])

#### Dependencies

  * [Squarespace plan][3] that supports [JavaScript][4].

---

## Quick Install

* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Store Page.
    
    * Add code from file **[store page detail slideshow item badge
      add.html][5]** to Store Page Settings > Advanced >
      Page Header Code Injection for the Page. Refer to [Inject code to a
      specific page][6] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Store Pages.
    
    * v7.1
    
      * Add code from file **[store page detail slideshow item badge
        add.html][5]** to Website > Pages > Custom Code > Code Injection >
        FOOTER.
        
    * v7.0
    
      * Add code from file **[store page detail slideshow item badge
        add.html][5]** to Website > Pages > Website Tools > Custom Code >
        Code Injection > FOOTER.
        
    * Refer to [Add code to the header and footer][7].
