# Store Page Commerce Elements Hide

### [License][1]

### Synopsis

Hide all commerce elements on a Store Page.

### Version

  * 1.1.1

#### Squarespace Versions

  * 7.1
  
  * 7.0 ([Adirondack template][2], [Supply template][3], [Wexley template][4])

---

## Install

* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Store Page.
    
    * Add code from file **[store page commerce elements hide.html][5]** to
      Store Settings > Advanced > Page Header Code Injection for the Store Page.
      Refer to [Inject code to a specific page][6] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Store Pages.
    
    * Add code from file **[store page commerce elements hide.less][7]** to
      Website > Pages > Custom Code > Custom CSS. Refer to [Add CSS code][8] for
      details.
      
* Read the code for any instructions within.
