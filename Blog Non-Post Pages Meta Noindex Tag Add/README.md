## Install

* Install [twcsl][7]. After you install twcsl be sure to continue on with the
  rest of the steps.
  
* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Blog Page.
    
    * Add code from file **[blog non-post pages meta noindex tag add.html][8]**
      to Blog Settings > Advanced > Page Header Code Injection for the Page.
      Refer to [Inject code to a specific page][9] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Blog Pages.
    
    * Add code from file **[blog non-post pages meta noindex tag add.html][8]**
      to Website > Pages > Custom Code > Code Injection > FOOTER. Refer to
      [Add code to the header and footer][10] for details.
