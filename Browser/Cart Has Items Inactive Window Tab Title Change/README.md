# Cart Has Items Inactive Window Tab Title Change

### [License][1]

### Synopsis

When the cart has items and the window/tab becomes inactive flip between the
standard Squarespace page title and a custom one.

### Version

  * 0.1.0

#### SS Versions

  * 7.1
  
  * 7.0

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Install Options

* CDN Hosted

  Use this option for the quickest way to install this effect (files hosted
  externally on the [jsDelivr][4], a [CDN][5])
  
  * Add code from file **[cart has items inactive window tab title change
    options.html][6]** to Website > Pages > Custom Code > Code Injection >
    FOOTER. Read the code for any instructions within.
    
  * Add the following code to Website > Pages > Custom Code >
    Code Injection > FOOTER.
    
    ```html
    <!-- begin TWC Cart Has Items Inactive Window Tab Title Change -->
    
      <!-- License < https://github.com/tomsWebConsulting/twcsl/blob/main/LICENSE.txt#L1 > -->
      
      <script src="https://cdn.jsdelivr.net/gh/tomsWebConsulting/twcsl@75170e8732b4e60253af564fdfbdf8e0bcebd5c8/Browser/Cart%20Has%20Items%20Inactive%20Window%20Tab%20Title%20Change/cart%20has%20items%20inactive%20window%20tab%20title%20change%20options.min.js" type="module"></script>
      
      <!-- end TWC Cart Has Items Inactive Window Tab Title Change -->
      
    ```
    
  * Refer to [Add code to code injection][7] for details.
  
* On-site

  Use this option to install the full code of this effect (files hosted on your
  site).
  
  * Add code from file **[cart has items inactive window tab title change
    options.html][6]** to Website > Pages > Custom Code > Code Injection >
    FOOTER. Read the code for any instructions within.
    
  * Add code from file **[cart has items inactive window tab title
    change.html][8]** to Website > Pages > Custom Code > Code Injection >
    FOOTER.
    
  * Refer to [Add code to code injection][7] for details.
