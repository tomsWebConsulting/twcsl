## Quick Install

* Add the following to Website > Pages > Custom Code > Code Injection > HEADER.

  ```html
  <script src="https://ajax.googleapis.com/ajax/libs/jquery/3.7.1/jquery.min.js"></script>
  ```
  
* Add code from file **[social icon discord generic icon to discord
  change.css][2]** to Website > Pages > Custom Code > Custom CSS. Refer to
  [Add CSS code][3] for details.
  
* Add code from file **[social icon discord generic icon to discord
  change.html][4]** to Website > Pages > Custom Code > Code Injection > FOOTER.
  Read the code for any instructions within.
  
* Add code from file **[social icon discord generic icon to discord change svg
  symbol.html][5]** to Website > Pages > Custom Code > Code Injection > FOOTER.
