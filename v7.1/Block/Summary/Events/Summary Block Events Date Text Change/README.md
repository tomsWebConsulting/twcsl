# Summary Block Events Date Text Change

### [License][1]

### Synopsis

Change text of summary block events dates.

### Version

  * 0.1.0

#### Squarespace Versions

  * 7.1

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Quick Install

* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Page.
    
    * Add code from file **[summary block events date text change.html][4]** to
      Page Settings > Advanced > Page Header Code Injection for the Page. Refer
      to [Inject code to a specific page][5] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Pages.
    
    * Add code from file **[summary block events date text change.html][4]** to
      Website > Pages > Custom Code > Code Injection > FOOTER. Refer to [Add
      code to the header and footer][6] for details.
