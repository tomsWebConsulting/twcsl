# Gallery Block Carousel Arrows Top Center

### [License][1]

### Synopsis

Move navigation arrows to above the images top center.

### Version

  * 0.1.1

#### Squarespace Version

  * 7.1

## Quick Install

* Add code from file **[gallery block carousel arrows top center.less][2]**
  to Website > Pages > Custom Code > Custom CSS. Refer to [Add CSS code][3] for
  details.
