# Store Page Products Panel Product Categories Copy

### [License][1]

### Synopsis

Copy categories from a selected Store Page Products Panel Product.

### Version

  * 0.2.0

#### SS Version

  * 7.1

---

## Quick Install

Add code from file **[store page products panel product categories
copy.bookmarklet][2]** as the URL for a bookmark in your browser named **TWC
Store Page Products Panel Product Categories Copy**.

## How to Use

* Go to a Store Page Products Panel.

* Select a Product.

* Use the bookmarklet.

## Notes

This effect makes a call to a JSON version of a Product's data.

This effect only copies Categories from the first selected Product.
