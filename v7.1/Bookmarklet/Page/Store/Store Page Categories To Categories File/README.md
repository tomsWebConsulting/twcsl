# Store Page Categories To Categories File

### [License][1]

### Synopsis

Add categories to a Store Page with no categories.

### Version

  * 0.1.1

#### SS Version

  * 7.1

---

## Quick Install

* Add code from file **[store page categories to categories
  file.bookmarklet][2]** as the URL for a bookmark in your browser named **TWC
  Store Page Categories To Categories File**.

## How to Use

* Navigate to a Store Page.

* Use the bookmarklet.

* Wait for the bookmarklet to finish its work.

  Watch a [video][3].
