# Store Page Products Panel Selected Categories Paste

### [License][1]

### Synopsis

Paste categories to selected Products in a Store Page Products Panel.

### Version

  * 0.1.1

#### SS Version

  * 7.1

#### Dependencies

  * [Store Page Products Panel Product Categories Copy][2]

---

## Quick Install

Add code from file **[store page products panel selected categories
paste.bookmarklet][3]** as the URL for a bookmark in your browser named **TWC
Store Page Products Panel Selected Categories Paste**.

## How to Use

* Go to a Store Page Products Panel.

* Select each Product which you want to paste Categories.

* Use the bookmarklet.

* Wait for the bookmarklet to notify you it is complete.

## Note

You must be careful using this effect as while it is not destructive it can make
massive additions of categories to your products.
