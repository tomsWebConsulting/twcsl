# Store Page to CSV File

### [License][1]

### Synopsis

Save Store Page products to a CSV file.

### Version

  * 0.1.0

#### SS Version

  * 7.1

---

## Quick Install

* Add code from file **[store page to csv file.bookmarklet][2]** as the URL for
  a bookmark in your browser named **TWC Store Page to CSV File**.

## How to Use

* Navigate to a Store Page.

* Use the bookmarklet.

## Extra Columns

In addition to the same columns contained in a standard Squarespace Product
Export CSV file, this code adds the following extra column:

* Categories Paths

  Category paths hierarchy. For products with multiple categories the field is
  comma separated.
  
  Examples
  
    * cyan, magenta, yellow
    
    * red > green > blue, cyan

## Note

Squarespace can not do anything with the extra CSV columns on Import. The extra
fields are purely for needs outside of Squarespace.
