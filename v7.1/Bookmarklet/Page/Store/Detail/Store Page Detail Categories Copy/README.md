# Store Page Detail Categories Copy

### [License][1]

### Synopsis

Copy categories from a Store Page Detail.

### Version

  * 0.1.0

#### SS Version

  * 7.1

---

## Quick Install

Add code from file **[store page detail categories copy.bookmarklet][2]** as the
URL for a bookmark in your browser named **TWC Store Page Detail Categories
Copy**.

## How to Use

* Go to a Store Page Detail Page.

* Use the bookmarklet.

## Note

This effect makes a call to the JSON version of the Store Page Detail Product
for information that is not normally available.
