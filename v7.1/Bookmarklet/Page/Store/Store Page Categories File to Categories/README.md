# Store Page Categories File to Categories

### [License][1]

### Synopsis

Add categories file to a Store Page with no categories.

### Version

  * 0.1.1

#### SS Version

  * 7.1

---

## Quick Install

* Add code from file **[store page categories file to
  categories.bookmarklet][2]** as the URL for a bookmark in your browser named
  **TWC Store Page Categories File to Categories**.

## How to Use

* Navigate to a Store Page with no categories.

* Use the bookmarklet.

* Wait for the bookmarklet to finish its work.

  Watch a [video][3].
