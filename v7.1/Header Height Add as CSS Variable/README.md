## Quick Install

* Add the following to Website > Pages > Custom Code > Code Injection >
  HEADER.
  
  ```html
  <script src="https://ajax.googleapis.com/ajax/libs/jquery/3.7.1/jquery.min.js"></script>
  ```
  
* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Page.
    
    * Add code from file **[header height add as css variable.html][2]** to Page
      Settings > Advanced > Page Header Code Injection for the Page. Refer to
      [Inject code to a specific page][3] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Pages.
    
    * Add code from file **[header height add as css variable.html][2]** to
      Website > Pages > Custom Code > Code Injection > FOOTER. Refer to [Add
      code to the header and footer][4] for details.

* Read the code for any instructions within.
