# Site Styles Cookie Banner Export

### [License][1]

### Synopsis

Export Site Styles Cookie Banner to a file.

### Version

  * 0.1.0

#### SS Version

  * 7.1

## Quick Install

* Add code from file **[site styles cookie banner export.bookmarklet][2]** as
  the URL for a bookmark in your browser named **TWC Site Styles Cookie Banner
  Export**.
