# Site Styles Cookie Banner Import

### [License][1]

### Synopsis

Import Site Styles Cookie Banner from a file.

### Version

  * 0.1.0

#### SS Version

  * 7.1

---

## Quick Install

* Add code from file **[site styles cookie banner import.bookmarklet][2]** as
  the URL for a bookmark in your browser named **TWC Site Styles Cookie Banner
  Import**.

## How to Use

* Use the bookmarklet.

* Wait for the site to reload.

## What is a bookmarklet?

Wikipedia has a nice entry on [bookmarklet][3].
