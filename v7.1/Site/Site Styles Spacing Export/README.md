### [License][1]

### Synopsis

Export Site Styles Spacing to a file.

### Version

#### SS Version

## Quick Install

* Add code from file **[site styles spacing export.bookmarklet][2]** as the URL
  for a bookmark in your browser named **TWC Site Styles Spacing Export**.
