# Site Styles Buttons Import

### [License][1]

### Synopsis

Import Site Styles Buttons from a file.

### Version

  * 0.1.0

#### SS Version

  * 7.1

---

## Quick Install

* Add code from file **[site styles buttons import.bookmarklet][2]** as the URL
  for a bookmark in your browser named **TWC Site Styles Buttons Import**.

## How to Use

* Use the bookmarklet.

* Wait for the site to reload.

## What is a bookmarklet?

Wikipedia has a nice entry on [bookmarklet][3].
