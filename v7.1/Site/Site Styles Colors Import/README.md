# Site Styles Colors Import

### [License][1]

### Synopsis

Import Site Styles Colors.

### Version

  * 0.1.1

#### SS Version

  * 7.1

---

## Quick Install

* Add code from file **[site styles colors import.bookmarklet][2]** as the URL
  for a bookmark in your browser named **TWC Site Styles Colors Import**.

## How to Use

* Use the bookmarklet.

* Wait for the site to reload.
