# Site Styles Fonts Export

### [License][1]

### Synopsis

Export Site Styles Fonts to a file.

### Version

  * 0.1.0

#### SS Version

  * 7.1

---

## Quick Install

* Add code from file **[site styles fonts export.bookmarklet][2]** as the URL
  for a bookmark in your browser named **TWC Site Styles Fonts Export**.

## What is a bookmarklet?
