# Site Styles Colors Export

### [License][1]

### Synopsis

Export Site Styles Colors to a file.

### Version

  * 0.2.0

#### SS Version

  * 7.1

---

## Quick Install

* Add code from file **[site styles colors export.bookmarklet][2]** as the URL
  for a bookmark in your browser named **TWC Site Styles Colors Export**.

## What is a bookmarklet?

Wikipedia has a nice entry on [bookmarklet][3].
