## Quick Install

* Site-wide Effect

  * Add code from file **[hide blog post tags.css][2]** to Website > Pages >
    Custom Code > Custom CSS. Refer to [Add CSS code][3] for details.
    
* Blog Only Effect

  * Add code from file **[hide blog post tags.html][4]** to Blog Settings >
    Advanced > Page Header Code Injection for the Blog Page.
