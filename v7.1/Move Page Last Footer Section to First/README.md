## Install

* Install [twcsl][2]. After you install twcsl be sure to continue on with the
  rest of the steps.
  
* Add code from file **[move page last footer section to first.css][3]** to
  Website > Pages > Custom Code > Custom CSS. Refer to [Add CSS code][4] for
  details.

* Add code from file **[move page last footer section to first.html][5]** to
  Page Settings > Advanced > Page Header Code Injection for the Page. Refer to
  [Inject code to a specific page][6] for details.
