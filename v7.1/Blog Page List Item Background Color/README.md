# Blog Page List Item Background Color

### [License][1]

### Synopsis

Copy blog page list meta after blog title.

### Version

  * 0.1.0

#### Squarespace Version

  * 7.1

---

## Quick Install

* Add code from file **[blog page list item background color.html][2]** to Blog
  Settings > Advanced > Page Header Code Injection for the Blog Page. Read the
  code for any instructions within. Refer to [Inject code to a specific page][3]
  for details.
