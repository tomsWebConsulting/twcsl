# Element Animate

### [License][1]

### Synopsis

Animate elements that Squarespace hasn't.

### Version

 * 0.3.0

#### Squarespace Version

  * 7.1
  
#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Quick Install

* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Page.
    
    * Add code from file **[element animate.html][4]** to Page Settings >
      Advanced > Page Header Code Injection. Refer to [Inject code to
      a specific page][5] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Pages.
    
    * Add code from file **[element animate.html][4]** to Website > Pages >
      Custom Code > Code Injection > HEADER. Refer to [Add code to the
      header and footer][6] for details.
      
* Read the code for any instructions within.
