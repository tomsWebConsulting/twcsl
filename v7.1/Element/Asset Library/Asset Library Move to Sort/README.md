# Asset Library Move to Sort

### [License][1]

### Synopsis

Alphabetically sort the folders listed in the Asset Library Move to... dialog.

### Version

  * 0.1.0

#### Squarespace Version

  * 7.1

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Quick Install

* Add code from file **[asset library move to sort.html][4]** to Website >
  Pages > Custom Code > Code Injection > HEADER. Refer to [Add code to the
  header and footer][5] for details.
