# Asset Library Move to Dialog Sort

### [License][1]

### Synopsis

Alphabetically sort the folders listed in the Asset Library Move to... dialog.

### Version

  * 0.1.0-development.0

#### Squarespace Version

  * 7.1

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].
  
  * [Effects][4]

## Install

* Activate this code using the **[Effects][5]** dialog.
