# Element Border

### [License][1]

### Synopsis

Add border around elements of a site.

### Version

  * 0.1.0

#### Squarespace Version

  * 7.1

#### Dependencies

  * LESS v1.3.3

---

## Quick Install

* Add code from file **[element border.less][2]** to Website > Pages >
  Custom Code > Custom CSS. Read the code for any instructions within. Refer to
  [Add CSS code][3] for details.
