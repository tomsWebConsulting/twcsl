# Events Page List Event Link

### [License][1]

### Synopsis

Make the whole Event a clickable link.

### Version

  * 0.1.0

#### Squarespace Version

  * 7.1

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Install Options

* CDN Hosted

  Use this option for the quickest way to install this effect (files hosted
  externally on the [jsDelivr][4], a [CDN][5])
  
  * Options
  
    * Page Specific
    
      Use this option when you want to have this effect on only one Events Page.
      
      * Add the following code to Page Settings > Advanced >
        Page Header Code Injection for the Events Page.
        
        ```html
        <!-- begin TWC Events Page List Event Link -->
        
          <!-- License < https://github.com/tomsWebConsulting/twcsl/blob/main/LICENSE.txt#L1 > -->
          
          <link href="https://cdn.jsdelivr.net/gh/tomsWebConsulting/twcsl@22c9588e9d4315e77d39dfe0fcede2bb95647fa6/v7.1/Page/Events/List/Events%20Page%20List%20Event%20Link/events%20page%20list%20event%20link.min.css" rel="stylesheet" type="text/css">
          
          <script src="https://cdn.jsdelivr.net/gh/tomsWebConsulting/twcsl@22c9588e9d4315e77d39dfe0fcede2bb95647fa6/v7.1/Page/Events/List/Events%20Page%20List%20Event%20Link/events%20page%20list%20event%20link.min.js" type="module"></script>
          
          <!-- end TWC Events Page List Event Link -->
          
        ```
        
        Refer to [Inject code to a specific page][6] for details.
        
    * Site-wide
    
      Use this option when you want to have this effect on all Events Pages.
      
      * Add the following code to Website > Pages > Custom Code >
        Code Injection > FOOTER.
        
        ```html
        <!-- begin TWC Events Page List Event Link -->
        
          <!-- License < https://github.com/tomsWebConsulting/twcsl/blob/main/LICENSE.txt#L1 > -->
          
          <link href="https://cdn.jsdelivr.net/gh/tomsWebConsulting/twcsl@22c9588e9d4315e77d39dfe0fcede2bb95647fa6/v7.1/Page/Events/List/Events%20Page%20List%20Event%20Link/events%20page%20list%20event%20link.min.css" rel="stylesheet" type="text/css">
          
          <script src="https://cdn.jsdelivr.net/gh/tomsWebConsulting/twcsl@22c9588e9d4315e77d39dfe0fcede2bb95647fa6/v7.1/Page/Events/List/Events%20Page%20List%20Event%20Link/events%20page%20list%20event%20link.min.js" type="module"></script>
          
          <!-- end TWC Events Page List Event Link -->
          
        ```
        
        Refer to [Add code to the header and footer][7] for details.
        
* On-site

  Use this option to install the full code of this effect (files hosted on
  your site).
  
  * Page Specific
  
    Use this option when you want to have this effect on only one Events Page.
    
    * Add code from file **[events page list event link.html][8]** to
      Page Settings > Advanced > Page Header Code Injection for the Events Page.
      Refer to [Inject code to a specific page][6] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Events Pages.
    
    * Add code from file **[events page list event link.html][8]** to Website >
      Pages > Custom Code > Code Injection > FOOTER. Refer to [Add code to the
      header and footer][7] for details.
