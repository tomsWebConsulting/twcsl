# Events Page List Horizontal Scroll

### [License][1]

### Synopsis

Reformat Events page list for horizontal scroll.

### Version

  * 0.1.0

#### Squarespace Version

  * 7.1

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Quick Install

* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Events Page.
    
    * Add code from file **[events page list horizontal scroll.html][4]** to
      Page Settings > Advanced > Page Header Code Injection for the Page. Refer
      to [Add code to the header and footer][5] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Events Pages.
    
    * Add code from file **[events page list horizontal scroll.less][6]** to
      Website > Pages > Custom Code > Code Injection > Custom CSS. Refer to
      [Add CSS code][16] for details.
      
* Read the code for any instructions within.
