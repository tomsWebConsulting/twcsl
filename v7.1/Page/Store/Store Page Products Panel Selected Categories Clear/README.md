# Store Page Products Panel Selected Categories Clear

### [License][1]

### Synopsis

Clear categories from a selected Store Page Products Panel Product.

### Version

  * 0.1.0

#### SS Version

  * 7.1

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].
  
  * [Store Page Products Panel Product Menu Item Add][4]

---

## Install

* Install code from **[Store Page Products Panel Product Menu Item Add][5]**.
  After you install the code be sure to continue on with the rest of the steps.
  
* Options

  * Page Specific
  
    Use this option if you want to have this effect on only one Store Page.
    
    * Add code from file **[store page products panel product categories
      clear.html][6]** to Store Settings > Advanced > Page Header Code Injection
      for the Store Page.
      
    * Refer to [per-page code injection][7] for details.
    
  * Site-wide
  
    Use this option if you want to have this effect on all Store Pages.
    
    * Add code from file **[store page products panel product categories
      clear.html][6]** to Website > Pages > Custom Code > Code Injection >
      HEADER.
      
    * Refer to [Add code to code injection][8] for details.

## How To Use

* In the Product Panel click the pop-up menu for a Product.

* Select the **Clear Categories** menu item.

## Note

You must be careful using this effect it will remove all Categories from a
Product.
