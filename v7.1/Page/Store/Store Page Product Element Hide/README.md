# Store Page Product Element Hide

### [License][1]

### Synopsis

Hide elements of store products.

### Version

  * 0.4.1

#### Squarespace Version

  * 7.1
  
#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Quick Install

* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Store Page.
    
    * Add code from file **[store page product element hide.html][4]** to Store
      Settings > Advanced > Page Header Code Injection for the Store Page.
      Refer to [Inject code to a specific page][5] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Store Pages.
    
    * Add code from file **[store page product element hide.html][4]** to
      Website > Pages > Custom Code > Code Injection > HEADER. Refer to [Add
      code to the header and footer][6].
      
* Read the code for any instructions within.
