# Store Page List Products Hide

### [License][1]

### Synopsis

Hide products on store page list page.

### Version

  * 2.0.0

#### Squarespace Version

  * 7.1

---

## Quick Install

* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Store
    Page.
    
    * Add code from file **[store page list products hide.html][2]** to
      Store Settings > Advanced > Page Header Code Injection for the Store Page.
      Refer to [Inject code to a specific page][3] for details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Store Pages.
    
    * Add code from file **[store page list products hide.less][4]** to
      Website > Pages > Custom Code > Code Injection > Custom CSS. Refer to
      [Using the CSS Editor][14] for details.
