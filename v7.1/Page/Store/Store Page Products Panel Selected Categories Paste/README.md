# Store Page Products Panel Selected Categories Paste

### [License][1]

### Synopsis

Paste categories to selected Products in a Store Page Products Panel.

### Version

  * 0.3.0

#### SS Version

  * 7.1

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].
  
  * [Store Page Products Panel Product Categories Copy][4]
  
  * [Store Page Products Panel Multiple Products Menu Item Add][5]

---

## Install

* Install code from **[Store Page Products Panel Multiple Products Menu Item
  Add][6]**. After you install the code be sure to continue on with the rest of
  the steps.
  
* Options

  * Page Specific
  
    Use this option if you want to have this effect on only one Store Page.
    
    * Add code from file **[store page products panel selected categories
      paste.html][7]** to Store Settings > Advanced > Page Header Code Injection
      for the Store Page.
      
    * Refer to [per-page code injection][8] for details.
    
  * Site-wide
  
    Use this option if you want to have this effect on all Store Pages.
    
    * Add code from file **[store page products panel selected categories
      paste.html][7]** to Website > Pages > Custom Code > Code Injection >
      HEADER.
      
    * Refer to [Add code to code injection][9] for details.

## How To Use

* Use [Store Page Products Panel Product Categories Copy][10] to copy
  Categories.

* In the Product Panel select Products.

* Click the **Paste Categories** menu item.

## Note

You must be careful using this effect as while it is not destructive it can make
massive additions of categories to your products.
