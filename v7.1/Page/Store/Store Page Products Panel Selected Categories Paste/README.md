# Store Page Products Panel Selected Categories Paste

### [License][1]

### Synopsis

Paste categories to selected Products in a Store Page Products Panel.

### Version

  * 0.2.0

#### SS Version

  * 7.1

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Install Options

* Page Specific

  Use this option if you want to have this effect on only one Store Page.
  
  * Add code from file **[store page products panel selected categories
    paste.html][4]** to Store Settings > Advanced > Page Header Code Injection
    for the Store Page.
    
  * Refer to [per-page code injection][5] for details.
  
* Site-wide

  Use this option if you want to have this effect on all Store Pages.
  
  * Add code from file **[store page products panel selected categories
    paste.html][4]** to Website > Pages > Custom Code > Code Injection > HEADER.
    
  * Refer to [Add code to code injection][6] for details.

## How To Use

* In the Product Panel Product pop up menu select the **Copy Categories** menu
item.
