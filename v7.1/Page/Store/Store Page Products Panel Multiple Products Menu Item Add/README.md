# Store Page Products Panel Multiple Products Menu Item Add

### [License][1]

### Synopsis

Add menu items to selected Products pop up menu in a Store Page Products Panel.

### Version

  * 0.2.1

#### SS Version

  * 7.1

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Install Options

* Page Specific

  Use this option if you want to have this effect on only one Store Page.
  
  * Add code from file **[store page products panel multiple products menu item
    add.html][4]** to Store Settings > Advanced > Page Header Code Injection
    for the Store Page.
    
  * Refer to [per-page code injection][5] for details.
  
* Site-wide

  Use this option if you want to have this effect on all Store Pages.
  
  * Add code from file **[store page products panel multiple products menu item
    add.html][4]** to Website > Pages > Custom Code > Code Injection > HEADER.
    
  * Refer to [Add code to code injection][6] for details.

## How To Use

* Use the [store page products panel multiple products menu item add
  register][7] file to create your own menu items.
  
* This effect passes a product id and a crumb to your callback function.

## Registration Example

Please see [store page products panel multiple products menu item add register
log][8] for a minimal example of how to register your menu item.
