# Store Page Detail Add To Cart Text Change On Quantity Change

### [License][1]

### Synopsis

Add quantity based text to Add to Cart button.

### Version

  * 0.1.0

#### Squarespace Version

  * 7.1
  
#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Install

* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Store
    Page.
    
    * Add code from file **[store page detail add to cart text change on
      quantity change options.html][4]** to Store Page Settings > Advanced >
      Page Header Code Injection for the Page. Read the code for any
      instructions within.
      
    * Add code from file **[store page detail add to cart text change on
      quantity change.html][5]** to Store Page Settings > Advanced >
      Page Header Code Injection for the Page.
      
    * Refer to [Inject code to a specific page][6] for details.
    
  * Site-wide
  
    Use this option when you want to have this effect on all Store Pages.
    
    * Add code from file **[store page detail add to cart text change on
      quantity change options.html][4]** to Website > Pages > Custom Code >
      Code Injection > FOOTER.
      
    * Add code from file **[store page detail add to cart text change on
      quantity change.html][5]** to Website > Pages > Custom Code >
      Code Injection > FOOTER.
      
    * Refer to [Add code to the header and footer][7].
