# Portfolio Page Project Collection Type Class Add

### [License][1]

### Synopsis

Add a class to Portfolio Pages projects.

### Version

  * 1.1.0

#### Squarespace Version

  * 7.1

#### Dependencies

  * [Squarespace plan][2] that supports [JavaScript][3].

---

## Quick Install

* Options

  * Page Specific
  
    Use this option when you want to have this effect on only one Portfolio
    Page.
    
    * Add code from file **[portfolio page project collection type class
      add.html][4]** to Project Settings > Advanced > Page Header Code Injection
      for the Portfolio Page. Refer to [Inject code to a specific page][5] for
      details.
      
  * Site-wide
  
    Use this option when you want to have this effect on all Portfolio Pages.
    
    * Add code from file **[portfolio page project collection type class
      add.html][4]** to Website > Pages > Custom Code > Code Injection > FOOTER.
      Refer to [Add code to the header and footer][6] for details.

## Class Name

The code adds the **twc-pppctca-collection-type-portfolio-project** class name
to the body tag.
