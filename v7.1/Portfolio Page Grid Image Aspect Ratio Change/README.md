## Install

* Install [twcsl][2]. After you install twcsl be sure to continue on with the
  rest of the steps.
  
* Add code from file **[portfolio page grid image aspect ratio change.html][3]**
  to Page Settings > Advanced > Page Header Code Injection for the Page. Refer
  to [Inject code to a specific page][4] for details.
  
* Read the code for any instructions within.
