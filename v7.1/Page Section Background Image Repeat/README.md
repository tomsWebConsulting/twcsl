## Quick Install

* Install code from **[Page Section Background Transparent][2]**.
  
* Add code from file **[page section background image repeat.html][3]** to
  Page Settings > Advanced > Page Header Code Injection for the Page. Read the
  code for any instructions within.

## Notes

This is meant as a base for other effects.

This effect works best with background images that have undifferentiated edges.
Like sand or a very tight weaved textile. It does not work with images that when
repeated the edges must match exactly to look good.
